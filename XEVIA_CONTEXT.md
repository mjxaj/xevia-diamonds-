## Project

- **Xevia Diamonds** — luxury fine-jewellery atelier site.
- **Client:** Kashish Goyal (listed as founder in copy; Raipur).
- **Built by:** MJX Labs.

## Stack

- **Runtime:** Node.js ≥ 22.5 (uses built-in `node:sqlite`, no native compile).
- **Server:** Express 4.
- **DB:** SQLite via `node:sqlite`, file at `data/xevia.db` (WAL mode — `.db-shm` / `.db-wal` present).
- **Views:** Nunjucks templates in `views/`.
- **Styling:** Tailwind via CDN + inline `<style>` blocks per page.
- **Auth/session:** `express-session` + `bcryptjs`.
- **Uploads:** `multer` writing to `public/uploads/`.
- **Mail:** `nodemailer` (SMTP creds deferred — see below).
- **Editable copy:** every string on the public site is driven by `settings` rows and editable at `/admin/settings` — nothing hardcoded.

## Deploy

- **Host:** Render (free tier), config in `render.yaml`.
- **Live URL:** https://xevia-diamonds.onrender.com
- **Custom domain:** xeviadiamonds.com (Hostinger DNS).
- **Repo:** https://github.com/mjxaj/xevia-diamonds- (note the trailing hyphen in the repo slug — real).
- **Env vars set via Render dashboard** (`sync: false` in render.yaml): `ADMIN_PASSWORD`, `CONTACT_*`, `SMTP_*`, `MAIL_FROM`, `NOTIFY_EMAIL`. `SESSION_SECRET` is generated by Render.
- **First-boot behavior:** `server.js` auto-runs `lib/seed.js` when `collections` table is empty.

## Pages

Public routes (`routes/public.js`):

- `/` — Home
- `/collections` — index of all collections
- `/collections/:slug` — collection detail (products in that collection)
- `/products/:slug` — product detail (+ related from same collection)
- `/portfolio` — 15-design gallery + downloadable `/portfolio.pdf`
- `/imagine` — Xevia Imagine (custom design / AI concept)
- `/about`, `/contact`
- `/privacy-policy`, `/terms-conditions`, `/refund-policy`, `/shipping-policy`
- `POST /subscribe` — newsletter (Private Circle), issues `XEV-NL-XXXXXX` refs, emails subscriber + admin

## Enquire Now flow

- Every "Buy Now" CTA on the site is replaced by an **Enquire Now** button that opens a modal (`views/partials/enquiry-modal.njk`).
- Modal fields: name, email, phone, budget, message, plus hidden `product_id` / `product_slug` / `enquiry_type`.
- `POST /enquiry` → validates → inserts into `enquiries` table with a generated `XEV-XXXXXX` reference → fires two emails (customer confirmation, admin notification with reply-to = customer). Uses `crypto.randomBytes(3)`.
- Emails are **fire-and-forget** after DB save. `customer_emailed` / `admin_emailed` flags update on success.
- **SMTP is wired but deferred** — enquiries still save to the DB when SMTP creds are missing.

## Admin (`/admin`)

- Login: `admin@xeviadiamonds.com` / `ChangeMe123!` (seed default — must be changed on first login).
- **Dashboard:** `GET /admin`
- **Enquiries:** list/filter/search (`GET /admin/enquiries`), detail with notes/status (`GET/POST /admin/enquiries/:id`), delete.
- **Products:** CRUD with image upload (`multer` → `public/uploads/`). `GET /admin/products`, `new`, `:id`, `POST /admin/products`, `POST /admin/products/:id`, `POST /admin/products/:id/delete`.
- **Collections:** CRUD with image upload.
- **Settings:** `GET/POST /admin/settings` — one big form driving every site string.
- **Account:** `POST /admin/account/password`.
